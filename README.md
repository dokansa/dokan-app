# تطبيق دكان — iPhone و Android

التطبيق واجهة ثانية لنفس متجر دكان: نفس المنتجات والأسعار والخصومات، نفس حسابات العملاء، نفس السلة والشحن بالوزن ورسوم الدفع عند الاستلام، ونفس بوابات الدفع (ماي فاتورة، تابي، تمارا). كل طلب من التطبيق ينزل في ووكومرس عادي ومعه علامة "تطبيق".

```
dokan-app/
├── app/                  تطبيق Flutter (iOS + Android)
├── wp-plugin/dokan-app-api/   إضافة ووردبريس تركّب على دكان
└── API.md                تفاصيل الربط بين التطبيق والمتجر
```

## ١) تركيب الإضافة على المتجر (جرّبها على نسخة الـ staging أول)
1. اضغط مجلد `wp-plugin/dokan-app-api` كملف zip.
2. ووردبريس ← إضافات ← أضف جديد ← رفع ← فعّلها.
3. ووكومرس ← **تطبيق دكان**، واملأ:
   - **رمز التحقق (OTP):** واتساب Cloud API (رقم الهاتف ID، التوكن، اسم قالب التحقق المعتمد من ميتا) أو بوابة SMS.
   - **الإشعارات:** ملف حساب الخدمة (Service Account JSON) من Firebase.
   - **Chatwoot:** رابط support.dokansa.com و Website Token لصندوق "Website".
   - رقم واتساب خدمة العملاء، نصوص التوصيل، البنرات.
4. في صفحة تعديل أي منتج أكل أو رمل تقدر تحدد **مدة الكفاية بالأيام** (عشان تذكير "قرب يخلص"). إذا تركتها فاضية تنحسب تقريبياً من الوزن.

> ما يحتاج أي مفاتيح ووكومرس أو ماي فاتورة داخل التطبيق. الدفع يمشي عن طريق إضافات الدفع المركبة أصلاً على الموقع.

## ٢) تشغيل التطبيق (على ماك)
```bash
cd app
bash setup.sh                       # ينشئ ملفات iOS و Android ويضبط الاسم والأيقونة
dart pub global activate flutterfire_cli
flutterfire configure               # يربط Firebase للإشعارات (اختر iOS و Android)
flutter run                         # يشغله على جوالك أو المحاكي
```
للتجربة على الـ staging بدل الموقع الحقيقي:
```bash
flutter run --dart-define=STORE_URL=https://staging.dokansa.com
```

## ٣) الإشعارات على الآيفون
في Firebase ← Project settings ← Cloud Messaging ارفع **APNs Auth Key** من حساب Apple Developer، وفعّل Push Notifications في Xcode (Signing & Capabilities).

## ٤) النشر
- **Android:** `flutter build appbundle` ← ارفعه على Google Play Console.
- **iOS:** `flutter build ipa` ← ارفعه من Transporter أو Xcode إلى App Store Connect.
- Apple تطلب: رابط سياسة الخصوصية، وزر حذف الحساب (موجود في "حسابي").

## اللي يسويه التطبيق
- الرئيسية: تبديل بين الحيوانات، تذكير إعادة الطلب، الأقسام، بنرات، منتجات مقترحة.
- المنتج: صور، خيارات (أحجام/أوزان)، كمية، إضافة للسلة.
- السلة والدفع: العنوان، الشحن حسب الوزن، كل طرق الدفع اللي مفعلة في دكان، رسوم الاستلام تنحسب تلقائي.
- الدفع: صفحة البوابة نفسها داخل التطبيق، ويرجع للطلب أول ما يتأكد الدفع.
- طلباتي: الحالة، مراحل الطلب، رابط تتبع شركة الشحن، طلب إلغاء (قبل الشحن فقط)، اطلبه مرة ثانية.
- ملف الحيوان: بياناته، كم باقي من أكله ورمله، تذكير قبل ما يخلص.
- خدمة العملاء: شات Chatwoot نفسه اللي يستخدمه فريقك، وزر واتساب.
- الدخول برقم الجوال، نفس حساب الموقع.
